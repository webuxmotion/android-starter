# Міні-курс: від «Hello World» до застосунку

Одинадцять уроків, у яких один і той самий проєкт поступово обростає
функціоналом.
Кожен урок — самодостатній крок: додаєш код, збираєш, ставиш на телефон,
комітиш. Через `git log` і `git diff` видно, яких саме файлів вимагала кожна
нова можливість — саме заради цього курс і побудований так.

## Як проходити

Перед кожним уроком переконайся, що робоче дерево чисте:

```sh
cd ~/nrf-projects/android-starter
git status
```

Далі — цикл, однаковий для всіх уроків:

```sh
# 1. правиш код за інструкцією уроку
# 2. збираєш і ставиш на телефон
./gradlew installDebug

# 3. дивишся, що саме змінилось
git status
git diff

# 4. фіксуєш крок
git add -A
git commit -m "Урок 3: лічильник зі станом"
```

Після коміту корисно глянути на нього збоку — це і є та «історія додавання
файлів», заради якої все затіяно:

```sh
git show --stat HEAD     # які файли зачепив останній коміт
git log --oneline --stat # те саме для всієї історії
```

## Якщо щось зламалось

```sh
git checkout -- app/src/main/java/.../MainActivity.kt  # відкотити один файл
git checkout -- .                                      # відкотити всі незакомічені зміни
git revert HEAD                                        # скасувати останній коміт новим комітом
git reset --hard HEAD                                  # жорстко повернутись до останнього коміту
```

Помилка збірки, яка виглядає як `Unresolved reference: Column`, майже завжди
означає забутий `import`. В Android Studio: `Alt+Enter` на червоному слові →
`Import`. У кожному уроці потрібні імпорти виписані явно.

## Умовності курсу

- Шлях `app/src/main/java/com/webuxmotion/androidstarter/` скорочую до `…/androidstarter/`.
- Блоки коду — це або **повний вміст файлу** (так і підписано), або фрагмент,
  куди його вставити описано словами.
- Команди виконуються з кореня проєкту (`~/nrf-projects/android-starter`).
- Збірка й установка описані в [../README.md](../README.md) — там же розбір
  типових помилок з `adb` і Java.

## Що варто знати наперед

Курс не пояснює синтаксис Kotlin з нуля, але й не вимагає його знання
досконало. Достатньо розуміти `val`/`var`, функції та класи. Специфічні для
Compose і Kotlin конструкції (`@Composable`, лямбда останнім аргументом,
делегат `by`, `data class`, корутини) пояснюються там, де вперше зустрічаються.
